# Ecommerce Sales Dashboard | Power BI

## Project Overview
This project presents an interactive Ecommerce Sales Dashboard developed using Microsoft Power BI. The dashboard helps analyze sales performance, profit, product quantity, payment methods, customer sales, and state-wise sales.

## Objectives
- Analyze total sales amount and profit.
- Track the quantity of products sold.
- Compare sales performance across different states.
- Analyze monthly profit trends.
- Understand customer-wise sales.
- Analyze payment methods used by customers.
- Compare product categories and sub-categories.

## Tools and Technologies
- Microsoft Power BI
- Data Visualization
- Business Intelligence
- Interactive Charts and Filters

## Dashboard Features
- Quarterly filters
- State filter
- KPI cards
- State-wise sales comparison
- Payment mode analysis
- Monthly profit analysis
- Customer-wise sales analysis
- Category-wise quantity analysis
- Sub-category profit comparison

## Conclusion
This dashboard provides a visual overview of ecommerce sales and profit performance. It helps identify important sales trends, understand customer payment preferences, compare regional performance, and evaluate product categories.
The analysis can support business decisions related to sales planning, product performance, and customer purchasing patterns.
